## 2026년 10월 8일 추가 구현 확인

이 복원 문서의 숨김·격리, 혼합 코드/그래프 계층, 긴 Lean 본문 편집, 원문 가져오기와 실제 선언 분석은 코드에 이미 반영되어 있다. 위 32 PASS·5 DEFERRED와 211 JS·166 Python은 당시 검사 기록으로 유지한다.

이 문서를 지목한 후속 요청에 따라 **Lean 원문에서 정리를 선택해 편집 가능한 GLEAN 선언 호출 그래프로 변환**하는 기능을 추가했다. 실제 정리 입력은 입력 노드·포트·와이어가 되며, 호출 LeanScript와 최종 목표를 편집·검사할 수 있다. 전체 원문과 최초 파일 바이트를 보존하고 원문 복귀·Undo/Redo·JSON 재열기를 지원한다. 원문·그래프·독립 목표를 각각 커널 검사하고 기존 공리 정책을 유지한다.

실제 π 호출 그래프는 170.568초에 `valid`, `verified=true`, 원문 커널 재검사 통과를 확인했다. 호출을 `by exact True.intro`로 바꾸면 134.526초에 실제 타입 오류로 거부되고 본문 1행 4열로 대응됐다. 이 CLI 대조는 총 240초 제한에서 실행했다. 같은 파일의 브라우저 재검사가 240초를 초과한 뒤 현재 원문 포함 그래프의 기본·상한은 총 360초로 조정했고 일반 검사의 총 120초는 유지했다. 추가 감사에서 발견한 취소 경쟁과 정리 누락도 수정했다.

새 검사 기록은 JS 전체 220개, Python 통합 전체 174개 통과와 취소 수정 후 관련 16개·독립 예산/HTTP 실험 14개 통과이다. 상세한 코드 범위·실험·브라우저 관찰과 제한은 [추가 구현 결과](../2026-10-08-lean-conversion/README.md)에 별도로 보관한다.
